## What it is

An informed public is supposed to be the point of a democracy, but staying informed usually means
picking between news that's biased and sensational, or objective and boring. Apathetic Times aims
for objective and engaging.

Each day it takes one report from the Congressional Research Service, Congress's nonpartisan
research group, and turns it into a briefing you can read in under five minutes. It has no spin
and never mentions political parties. You and a few friends share a room, vote on the day's
statement with a row of five faces from "No way" to "Totally", and talk it over.

## How it's built

- **Report pipeline.** Cloudflare Workflows run on a daily schedule. They pull new CRS reports from
  the Congress.gov API, extract the text from the PDFs into R2, summarize each one, and save it to
  D1. Each step is retried on its own, so a flaky PDF never reruns the whole batch.
- **Briefings with Claude.** A second workflow uses the Anthropic SDK to pick the day's report and
  write the briefing. The output is constrained to a Zod schema, so the app always gets valid,
  typed content back.
- **Real-time rooms.** Each chat room is a Durable Object holding hibernatable WebSockets, so
  messages and votes reach everyone instantly without a server sitting idle.
- **No accounts.** You pick a username and share a room link, and the app installs as a PWA.
